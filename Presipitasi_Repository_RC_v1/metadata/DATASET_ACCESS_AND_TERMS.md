# GloFAS v5 Historical: access and data-use terms

Dataset: River discharge and related historical data from the Global Flood Awareness System (GloFAS)
Dataset short name: `cems-glofas-historical`
Provider: Copernicus Emergency Management Service (CEMS), Early Warning Data Store (EWDS)
Dataset DOI: 10.24381/cds.a4fdd6b9
Official dataset page: https://ewds.climate.copernicus.eu/datasets/cems-glofas-historical
Access date for the manuscript acquisition record: 14 October 2026

The analysis uses GloFAS v5 Historical data. Raw monthly source files are not redistributed in this
repository release; users should retrieve the source data from the official EWDS dataset page and
accept the applicable CEMS-FLOODS datasets licence before downloading.

The CEMS-FLOODS datasets licence grants free access and permits reproduction, distribution,
communication to the public, adaptation, modification, and combination with other data and
information, subject to its terms and applicable law. When communicating or distributing CEMS
EFAS/GloFAS data, the source should be acknowledged using the prescribed or similar attribution:
"Generated using Copernicus Emergency Management Service information [Year]".
When data are adapted or modified, the licence provides the corresponding modified-data notice.

Users must comply with the current EWDS/CEMS licence and terms of use in force at the time of
access. The repository does not replace the official source or the official licence.
